# Daftar Screenshot untuk Google Docs

Tempelkan screenshot asli dari komputer dan WhatsApp yang digunakan untuk pengujian.

1. Form registrasi sebelum diisi.
2. Form registrasi setelah diisi (tutup sebagian data pribadi bila perlu).
3. Tabel `users` di phpMyAdmin yang menunjukkan data tersimpan.
4. Pesan WhatsApp yang benar-benar diterima di nomor pengujian.
5. Source code `functions/fonnte.php`: function `kirimWhatsApp()` dan request cURL.
6. Source code `proses/register.php`: validasi, INSERT, pembuatan pesan dinamis, pemanggilan function, dan penyimpanan log.
7. Tabel `log_whatsapp` yang menunjukkan status pengiriman.
8. Pengujian email/nomor duplikat.
9. Pengujian ketika token Fonnte belum tersedia atau API gagal.
10. Halaman laporan notifikasi WhatsApp admin.

Jangan menampilkan token Fonnte atau password dalam screenshot.
